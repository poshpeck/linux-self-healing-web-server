# Project Evidence

This directory contains evidence demonstrating the functionality, testing and successful implementation of the Linux Self-Healing Web Server.

## Evidence Contents

| Evidence | Description |
|---|---|
| Server Status | Screenshots showing the web server running |
| Health Checks | Evidence of server health monitoring |
| Failure Detection | Demonstration of service failure detection |
| Automatic Recovery | Evidence of automatic service restart |
| Logs | Relevant system and application logs |
| Testing | Results from functional and recovery tests |

## Purpose

The evidence provided here validates the self-healing capabilities of the web server and demonstrates its ability to detect failures and automatically recover services.
